Exercício 03

1. Numa grupo de chat, quando um utilizador envia uma mensagem, todos os outros utilizadores devem de recebê-la.
No entanto, se essa mensagem fosse enviada individualmente para todos, além do número de ligações ser muito alto,
os utilizadores ficariam a saber o endereço IP uns dos outros, expondo a sua localização.

2. Para resolver este problema, cada utilizador comunica exclusivamente com um servidor, que encaminha a mensagem
para todos os outros. Assim, cada utilizador possui apenas uma ligação (com o servidor) e apenas o servidor
conhece a sua localização.
