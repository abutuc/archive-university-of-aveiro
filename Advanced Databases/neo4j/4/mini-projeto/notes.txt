In this mini-project I make some simplifying assumptions, namely:
- Author and Publisher are uniquely identified by their name, therefore, in the generated
    csv files, it may happen that two or more authors or publishers share a name and will get overwritten.

csv_generator.py -> generated csv files with database data (this file has randomization and overwrites previous csv files)
data_inserter.py -> takes data from the csv files generated by the csv_generator and inserts it into the neo4j database "books".
queries.py -> makes queries to the data base and writes everything to the CBD_L44c_output.txt file (some queries may return an empty
array regarding the csv_generator.py data generation. For example: users that mutually follow each other).
